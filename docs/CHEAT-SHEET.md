# Founder Conversation Cheat Sheet

*Keep this open during customer conversations.*

---

## The three rules
1. **Their life, not your idea.**
2. **Specifics in the past, not opinions about the future.**
3. **Talk less. Listen more.**

## Before you start
- Three big questions written. Which one scares you? **Ask it first.**
- Idea stays in your pocket until every discovery box is filled.
- Solution-stage? Decide the commitment you'll ask for (time / intro / money).

## The path
```
Hardest part of X?  →  When did that last happen?  →  Walk me through it.
→  What did it cost?  →  How many times last month?  →  How do you handle it now?
→  What have you tried? Why didn't it stick?  →  Ever paid for anything?
→  Who decides?  →  Why does it matter now?  →  Where does it rank?
→  [flip ONLY if all filled: one sentence in THEIR words + "what would make this not work?"]
→  Ask for commitment with a date  →  Who else? What did I miss?
```

## Reflexes
| Hear | Say |
|---|---|
| Compliment | "Thanks. How do you handle that today?" |
| "Always / never / all the time" | "When did that last happen?" |
| "I would / I'd definitely" | "What are you using now?" |
| "You should add X" | "Why? What would that let you do?" |
| Sigh, laugh, "honestly…" | "Say more about that." *(then silence)* |
| Objection | "Exactly what I need. What would it need to do?" |
| "It depends / it's fine" | "On what? What's the least-fine part?" |
| Vague warmth at the end | "Would you [trial / intro / pilot] next week?" |

## Never say
would · could · might · do you think · do you like · are you interested · would you pay · how much would you pay · good idea? · on a scale of

## Listen for
**Specifics** (dates, numbers) · **Money** (pay, spent, budget, canceled) · **Time** (hours, every Friday, stayed late) · **Workarounds** (spreadsheet, intern, "what I actually do") · **Emotion** (dread, hate, don't get me started) · **Urgency** (deadline, new boss, audit, "we're looking now") · **Constraints** (can't, IT, legal) · **Decision path** (names, sign-off) · **Contradictions** · **Absences** (no incident, no number, no spend)

## Alarms (you drifted)
compliments · fluff words · you've talked > 30% · nothing has surprised you · they're "doing you a favor"

## Evidence ladder
```
NOTHING     compliment · opinion · "I would" · "I'd pay $X" · feature request · "yeah, that's a pain"
PROBLEM     dated incident · emotion · consequence · objection · active search · workaround · time spent · $ spent
SOLUTION    30-min trial booked · intro sent · engineer assigned · money paid
```
Only PROBLEM and SOLUTION rungs count. Cost to them = weight.

## Meeting result (solution stage)
**Commitment or advancement = success. Anything else = fail.** "Keep me posted" is a fail.

## After (15 minutes)
3 exact quotes · every number · current solution + cost · names · surprises · commitments with dates · your drift count
Facts in one column, guesses in the other. Update assumptions. Follow up on every name within 24h.

## Reminders
- Bad news is progress. "Meh" is a verdict.
- Complaint without action is entertainment.
- Price against the workaround, not the wishlist.
- When answers scatter, narrow the who.
- If only you heard it, the team didn't learn it.
- Fix the question, not the person.
