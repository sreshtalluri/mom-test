# The Mom Test → Founder Conversation Skill

A practical operating manual built from Rob Fitzpatrick's *The Mom Test*. Not a summary. The goal is a repeatable skill for customer discovery, outreach, interviews, and product decisions.

Throughout, ideas are tagged:

- **[Book]** — Fitzpatrick's idea, restated in my own words
- **[Synthesis]** — my extension, framework, or operationalization built on top of the book

## Fastest path to using this

1. Read `CHEAT-SHEET.md` (5 min).
2. Before your next conversation, fill in the **Customer Interview Template** in `07-templates.md`.
3. After it, score yourself with the **Conversation Scorecard** in `06-training.md`.
4. Read the rest when a score tells you where you're weak.
