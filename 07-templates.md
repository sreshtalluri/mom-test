## 15.3 Discovery Call Template (30-minute structure)

```
0:00  Open casual. State purpose in one sentence. Hand them the floor.
      "I'm trying to understand how [role] handles [area]. What does a normal [week] look like?"

0:03  Broad problem ranking.
      "What's the hardest / most annoying part?"

0:05  ASK THE SCARY QUESTION. Do not let it slide to the end.

0:07  Anchor and expand.
      "When did that last happen?" → "Walk me through it." → "What did it cost?"

0:12  Current solution.
      "How do you handle it today?" → "What have you tried?" → "Why didn't that stick?"

0:17  Frequency, decision, urgency.
      "How many times last month?" · "Who decides on fixes?" · "Why does this matter now?"

0:21  Priority.
      "Where does this rank against everything else?"

0:23  [Only if solution-stage AND every box above is filled]
      One-sentence flip tied to their words. "What would make this not work?"
      Ask for commitment with a date.

0:27  Close.
      "Who else should I talk to?" · "Anything I should have asked?"

0:30  End on time. Ask for more only if they're clearly engaged.
```

## 15.4 Outreach Message Template

**[Book's five-part framing: Vision → Framing → Weakness → Pedestal → Ask]**

```
Subject: how you handle [specific thing]

Hi [Name],

[VISION] I'm working on making [specific pain] less painful for [specific role/segment].
[FRAMING] I'm not selling anything — I'm early and trying to understand this properly before building the wrong thing.
[WEAKNESS] I'm stuck on one thing: [a genuine, specific unknown; e.g., "I can't tell whether the pain is in building the schedule or in reacting when it breaks"].
[PEDESTAL] You've [specific credential: run ops at two carriers / built this at X / posted about this in Y], which is more experience than almost anyone I've found.
[ASK] Could I get 15 minutes to hear how it actually works at [their company]?

[Your name]
```

**Rules:** under 120 words. One specific weakness. One specific credential. A small ask. No link to your product. No "would love your feedback on my idea."

**Warm-intro version** (send to the introducer, ready to forward):
```
Hi [Introducer], thanks for offering. Here's something you can forward:

"[Name] is working on [vision]. They're not selling, they're trying to understand [weakness]. I mentioned you because [pedestal]. Could you spare 15 minutes?"
```

## 15.5 Follow-Up Message Template

**After a discovery conversation:**
```
Subject: thanks — and one thing you said

[Name], thanks for the time today. The thing that stuck with me was [specific quote or fact they gave: "three hours every Sunday"]. That's changed how I'm thinking about [specific thing].

[If they offered a name] You mentioned [Name]. Would you be up for a quick intro? Happy to send a note you can forward.

[If not] Who else do you think I should be talking to about this?

[Your name]
```

**After a solution-stage conversation with a commitment:**
```
Subject: [Date] — confirming

[Name], confirming [the commitment: 30 minutes Tuesday at 3 to set up on the school renovation bid]. I'll bring [specific thing]. You mentioned [Dana] should be there — has she been looped in?

[Your name]
```

**Reviving a zombie lead (one attempt only):**
```
Subject: quick yes/no

[Name], I know things are busy. One concrete ask: would you run [product] on [one specific real task] next week, with me setting it up? If the answer's no, that's genuinely useful too — I'd rather know.

[Your name]
```

**Note on thresholds:** the percentages are starting points, not rules. Set them before the batch, so you can't move the goalposts afterward.
